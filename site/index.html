The main add-on

Sterling Quest Sync

v0.3.19 · Free, open source (MIT)

Quest-log sync

Share quest logs with up to 10 friends. See who has a quest, who's ready to turn it in and who's done, right on tooltips, map pins and the quest log.

Live compare

When you're online together, changes sync as they happen. Side by side, you can see exactly where your logs differ.

Catch-up path

Pick a friend and a zone and get the quests they did that you haven't, as a route with an arrow to the next stop.

Sessions

Record a play session and send it to a friend so they can follow your exact route, with a map trail and playback.

Screenshots use made-up characters.

Optional Windows app

Sterling Quest Sync Companion

v0.1.29 · Windows

Syncs your quests with friends even when you play at different times. You don't need it to sync while you're online together.

  1. You log out. The game saves your progress.
  2. The Companion app sends it to the free Sterling sync server.
  3. Your friend's Companion app brings it down, ready for their next login.

It works both ways, pairs with your Sterling partners on its own, and updates itself. No email or password.

Download for Windows Troubleshooting

Windows may say "Windows protected your PC" the first time. Click More info, then Run anyway.

Install

Two ways to install

WowUp Recommended

  1. Install WowUp and point it at your WoW Forever folder.
  2. Open Get Addons, then Install from URL.
  3. Paste the add-on's link and install. Updates show up on their own after that.
  4. Start the game fresh. A /reload doesn't pick up new add-ons.
  • Sterling Quest Sync https://github.com/SterlingAddons/SterlingQuest
  • Sterling Loot Tracker https://github.com/SterlingAddons/SterlingLoot
  • Sterling Hunter https://github.com/SterlingAddons/SterlingHunter

Manual zip

  1. Download the add-on's zip from its download button above.
  2. Unzip it into World of Warcraft\_forever_\Interface\AddOns\. You should end up with a folder like AddOns\Sterling.
  3. Start the game fresh and make sure the add-on is ticked in AddOns at character select.
  4. To update, do the same again with the newer zip.

Using the CurseForge app? Sterling Quest Sync is on CurseForge: search for it in the app and it updates from there. Loot Tracker and Hunter are WowUp or zip only.
